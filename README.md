# Doka — Landing Page / Shop

A modern furniture store website with an emphasis on visual product presentation and user-friendly navigation.

## Features

- Responsive landing page
- Adaptive navigation with mobile menu
- Smooth scrolling
- BEM-based CSS architecture
- Tailwind CSS utilities organized in component styles

## Sections

- Header
- Category
- Hero
- Advantages
- Shop
- Partners
- About
- Reviews
- Reupholstery
- Footer

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- Heroicons
